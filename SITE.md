# Site Structure: Cookflow

## 1. Vision

Cookflow is a modern recipe management and cooking workflow application. It helps users organize recipes, plan meals, and cook with efficiency.

## 2. Stitch Project

**Project ID:** projects/889224776793372108

## 3. Key Pages (Sitemap)

- [x] **Home / Dashboard**: Overview of recent recipes, meal plan for the day, and quick actions.
- [x] **Chef Progress Dashboard** (Existing)
- [x] **Culinary Skills Gallery** (Existing)
- [x] **Course Lesson Interface** (Existing)
- [x] **Landing Page v1** (Existing)
- [x] **Recipe List**: Searchable, filterable list of all recipes.
- [x] **Recipe Detail**: Full view of a recipe with ingredients, steps, and cooking mode.
- [x] **Meal Planner**: Calendar view for planning meals.
- [x] **Shopping List**: Generated list of ingredients to buy.
- [x] **Cooking Mode**: Full-screen immersive step-by-step cooking interface with timer.
- [x] **Chef List**: Grid of all chefs with search, rating, courses, and student count.
- [x] **Chef Profile**: Banner, avatar, skills showcase, culinary creations, chef stats.
- [x] **Community (The Brigade)**: Post feed, like/bookmark, tabs, trending topics sidebar.
